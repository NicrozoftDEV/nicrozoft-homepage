## 直连（推荐）

使用下方地址即可直接加入服务器，无需安装任何额外软件：

- **Java 版地址：** `mcje.nicrozoft.org`
- **基岩版地址：** `mcbe.nicrozoft.org`，端口 `23457`

服务器通过跨版本与基岩适配插件支持 Java 版 `1.7.10 ~ 26.3`、基岩版 `26.30 ~ 26.51` 加入，推荐使用 Java 版 `26.2`（服务器当前版本）。

### EasyTier

你可以在 <a href="https://github.com/EasyTier/EasyTier/releases" target="_blank" rel="noopener noreferrer">EasyTier/EasyTier releases</a> 下载 EasyTier，或下载猫娘开发的 <a href="https://polaris.l5z12.dev/" target="_blank" rel="noopener noreferrer">Polaris</a>，随后加入虚拟网络：

- **网络名称：** `Nicrozoft_Network_New`
- **节点（手动设置）：** `udp://225284.xyz:11010`
- **Java 版加入地址：** `et.nicrozoft.org`
- **基岩版加入地址：** `et.nicrozoft.org`，端口 `23457`

### Radmin

你可以在 <a href="https://www.radmin-lan.cn" target="_blank" rel="noopener noreferrer">radmin-lan.cn</a> 下载，随后加入虚拟网络（私人网络）：

- **网络：** `Nicrozoft_Network`
- **密码：** `123456`
- **Java 版加入地址：** `ra.nicrozoft.org`
- **基岩版加入地址：** `ra.nicrozoft.org`，端口 `23457`

### OpenFrp

此为 OpenFrp 链接，可以直连，但存在较大延迟，该链接并不常开：

- **Java 版加入地址：** `cn-hk-bgp-4.ofalias.net:27452`
