**已开服一年有余** ** Leaves 分支 · Java 26.2**

## 简介

Nicrozoft 服务器是基于自行维护的本地 Leaves 服务端分支的 Minecraft Java 版 26.2 的生存服务器，以原版技术型生存（以下简称“生电”）和建筑玩法为主，兼顾探险、PVP、维度玩法（维度玩法将于后续开放）。 服务端为自行维护的分支，移植了生电必需和辅助的机制、特性与功能，支持大型生电红石机器的建造和运行，目前已建造众多机器，已实现部分资源的量产。 欢迎生电玩家前来为服务器发展出一份力，也欢迎建筑玩家来建造独属于你自己的建筑！

服务器使用白名单制，对于身份验证采用正版-离线混合机制。加入 QQ 群组后，需 @ 群主并报告用户名以申请加入白名单。 加入白名单后，正版玩家可直接进服游玩；而离线(含 LittleSkin)玩家首次进服需要设置密码，后续需要验证密码，以防止同用户名数据盗用。 如果离线玩家与正版用户重名，需要更名才能进服，可在 <a href="https://namemc.com/search" target="_blank" rel="noopener noreferrer">http://namemc.com/search</a> 查询。 如离线玩家后续转为同名正版账号，可执行 `/premium` 以切换到正版，后续不再需要验证密码，如转为不同名称的正版账号，可联系服主 Nicrozoft 以进行玩家数据迁移。 原则上不受理转为异名 LittleSkin 账号的数据迁移请求。

<span class="warn">本服务器不欢迎故意破坏公共设施或他人资产的玩家加入。如果你存在这类倾向，请移步无规则服务器。</span>
